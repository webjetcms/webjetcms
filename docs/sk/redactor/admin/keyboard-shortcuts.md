# Klávesové skratky

Prehľad otvoríte z hlavičky administrácie cez **Pomocník → Klávesové skratky**. Skratky závisia od miesta, kde práve pracujete: rovnaké klávesy môžu mať iný význam v texte, tabuľke alebo Prieskumníkovi.

Zápis **Ctrl / ⌘** znamená **Ctrl** vo Windows a Linuxe a **Command (⌘)** na Macu. **Alt** je na Macu kláves **Option (⌥)**. Pri funkčných klávesoch môže byť potrebné podržať aj **Fn**. Ak skratku preberie prehliadač alebo operačný systém, použite príslušné tlačidlo v administrácii.

## Vyhľadávanie a ovládanie administrácie

| Klávesy | Činnosť | Kde fungujú |
| --- | --- | --- |
| Ctrl / ⌘ + K | Otvoriť rýchle vyhľadávanie. | Mimo textových polí, editora a otvorených dialógov. |
| Alt + ← / → | Prepnúť rozsah vyhľadávania. | Vo vstupnom poli rýchleho vyhľadávania. |
| ↑ / ↓ | Prejsť na predchádzajúci alebo nasledujúci výsledok. | Vo vstupnom poli alebo na výsledku rýchleho vyhľadávania. |
| Enter | Spustiť vyhľadávanie alebo otvoriť označený výsledok. | Vo vstupnom poli, respektíve na odkaze výsledku. |
| Esc | Zavrieť rýchle vyhľadávanie a vrátiť sa na tlačidlo v hlavičke. | V dialógu rýchleho vyhľadávania. |
| Tab / Shift + Tab | Prejsť na nasledujúci alebo predchádzajúci ovládací prvok. | V administrácii a dialógoch. |
| Enter / medzerník | Aktivovať tlačidlo; Enter otvorí aj odkaz. | Na prvku označenom klávesnicou. |

Podrobnosti sú v návode [Vyhľadávanie](search/README.md).

## Datatabuľky a ukladanie

| Klávesy | Činnosť | Kde fungujú |
| --- | --- | --- |
| Ctrl / ⌘ + S | Uložiť záznam a ponechať editor otvorený. | V editore datatabuľky vrátane editora webovej stránky. Musí byť otvorené iba jedno dialógové okno a aplikácia musí podporovať ukladanie skratkou. |
| Enter / medzerník | Označiť alebo odznačiť riadok. | Na samotnom riadku tabuľky označenom klávesnicou, nie na odkaze v riadku. |
| Enter / medzerník | Otvoriť úpravu bunky. | Na bunke v zapnutom režime úpravy buniek. |
| ↓ | Presunúť sa z poľa dátumu do kalendára. | Ak je výber dátumu už otvorený. |
| ← / → | Posunúť sa o jeden deň. | Na dni v kalendári. |
| ↑ / ↓ | Posunúť sa o týždeň. | Na dni v kalendári. |
| Enter / medzerník | Vybrať deň. | Na dni v kalendári. |
| Esc | Zavrieť výber dátumu a vrátiť sa do poľa. | V otvorenom výbere dátumu. |

Uloženie cez **Ctrl / ⌘ + S** funguje aj v texte webovej stránky a v Page Builderi. Ak otvoríte ďalší dialóg, napríklad nastavenia odkazu, najprv ho zatvorte. Viac o práci s tabuľkami je v návode [Datatabuľky](../datatables/README.md).

## Textový editor webových stránok

Nasledujúce skratky sa používajú pri písaní v editore. Najmä **Ctrl / ⌘ + K** tu otvorí nastavenia odkazu; rýchle vyhľadávanie administrácie sa pri písaní neotvára.

| Klávesy | Činnosť |
| --- | --- |
| Ctrl / ⌘ + B | Zapnúť alebo vypnúť tučné písmo. |
| Ctrl / ⌘ + I | Zapnúť alebo vypnúť kurzívu. |
| Ctrl / ⌘ + U | Zapnúť alebo vypnúť podčiarknutie. |
| Ctrl / ⌘ + K | Vložiť alebo upraviť odkaz. Editor podporuje aj Ctrl / ⌘ + L, pokiaľ ho nepreberie prehliadač. |
| Ctrl / ⌘ + Z | Vrátiť poslednú úpravu textu. |
| Ctrl / ⌘ + Y alebo Ctrl / ⌘ + Shift + Z | Zopakovať vrátenú úpravu textu. |
| Ctrl / ⌘ + A | Označiť obsah editora. |
| Ctrl / ⌘ + C / X / V | Kopírovať, vystrihnúť alebo vložiť text. |
| Enter | Vytvoriť nový odsek. |
| Shift + Enter | Vložiť zalomenie riadka v odseku. |
| Shift + medzerník | Vložiť pevnú medzeru, na ktorej sa text nezalomí. |
| Ctrl + Q | Prepnúť na zdrojový HTML kód, ak ho editor sprístupňuje. Na Macu použite tlačidlo **Zdroj**, pretože ⌘ + Q ukončuje aplikáciu. |
| Alt + F10 | Presunúť sa na panel nástrojov editora. |
| Alt + F11 | Presunúť sa na cestu HTML elementov pod editorom, ak je zobrazená. |
| Shift + F10 alebo Ctrl / ⌘ + Shift + F10 | Otvoriť kontextové menu editora. |
| Ctrl / ⌘ + Shift + 3 / 4 | Presunúť sa na predchádzajúce alebo nasledujúce miesto na vloženie odseku pomocou pomocnej čiary. |

Vloženie čistého textu je dostupné cez tlačidlo **Vložiť ako čistý text**. Skratku pre vloženie bez formátovania poskytuje aj prehliadač a jej podoba závisí od prehliadača a systému. Pre vloženie z Wordu alebo Excelu použite príslušné tlačidlo na paneli nástrojov.

Podrobnosti sú v návode [Práca v editore](../webpages/working-in-editor/README.md).

## Úvodná obrazovka

Tieto klávesy fungujú počas úpravy prehľadu alebo skratiek na [úvodnej obrazovke](welcome.md).

| Klávesy | Činnosť | Kde fungujú |
| --- | --- | --- |
| Ctrl / ⌘ + Z | Vrátiť poslednú úpravu prehľadu. | V režime úpravy prehľadu, mimo textových polí a dialógov. |
| Medzerník / Enter | Začať presúvanie widgetu alebo skratky. | Na úchyte na presúvanie. |
| ← / → | Presunúť vybraný widget alebo skratku. | Po začatí presúvania klávesnicou. |
| ↑ / ↓ | Presunúť widget do predchádzajúceho alebo nasledujúceho riadka. | Pri presúvaní widgetu v prehľade. |
| Enter / medzerník | Potvrdiť pozíciu. | Pri presúvaní klávesnicou. |
| Esc | Zrušiť presúvanie. | Pri presúvaní klávesnicou. |
| Tab | Zrušiť presúvanie a prejsť na ďalší ovládací prvok. | Pri presúvaní klávesnicou. |

## Page Builder

V stromovej štruktúre [Page Buildera](../webpages/pagebuilder.md) môžete používať tieto klávesy:

| Klávesy | Činnosť |
| --- | --- |
| ↑ / ↓ | Prejsť na predchádzajúci alebo nasledujúci viditeľný prvok. |
| ← | Zbaliť vetvu alebo prejsť na nadradený prvok. |
| → | Rozbaliť vetvu alebo prejsť na jej prvý vnorený prvok. |
| Home / End | Prejsť na prvý alebo posledný viditeľný prvok. |
| Enter / medzerník | Vybrať prvok na úpravu. |

Na kartách pracovného panela a knižnice použite **← / →** na prepnutie karty a **Home / End** na prvú alebo poslednú kartu.

## Prieskumník a editor súborov

Skratky [Prieskumníka](../files/fbrowser/README.md) fungujú, keď je aktívna jeho plocha so súbormi. Dostupnosť operácií sa riadi vašimi oprávneniami a vybraným súborom alebo priečinkom. Pri písaní v editore súboru sa používajú skratky textového editora.

| Klávesy | Činnosť |
| --- | --- |
| Šípky | Presúvať výber medzi súbormi. |
| Shift + šípky | Rozšíriť výber súborov. |
| Home / End | Vybrať prvý alebo posledný súbor. |
| Ctrl / ⌘ + A | Vybrať všetky súbory. |
| Ctrl / ⌘ + Shift + I | Obrátiť výber. |
| Ctrl / ⌘ + C / X / V | Kopírovať, vystrihnúť alebo vložiť súbory. |
| Ctrl / ⌘ + ↓ | Otvoriť vybraný priečinok alebo súbor. Vo Windows a Linuxe funguje aj Enter. |
| Ctrl / ⌘ + ↑ | Prejsť do nadradeného priečinka. |
| Ctrl / ⌘ + ← alebo Backspace | Prejsť späť. |
| Ctrl / ⌘ + → | Prejsť dopredu. |
| Ctrl / ⌘ + Home alebo Ctrl / ⌘ + Shift + ↑ | Prejsť do domovského priečinka. |
| Medzerník | Otvoriť rýchly náhľad. |
| F2 | Premenovať vybraný súbor alebo priečinok. Na Macu funguje aj Enter. |
| Shift + F2 | Hromadne premenovať viacero vybraných súborov. |
| Delete alebo Ctrl / ⌘ + Backspace | Spustiť odstránenie vybraných súborov. |
| Ctrl / ⌘ + Shift + N | Vytvoriť priečinok. |
| Ctrl / ⌘ + U | Otvoriť nahrávanie súborov. |
| Shift + Enter | Stiahnuť vybrané súbory. |
| Ctrl / ⌘ + I | Zobraziť informácie o výbere. |
| Ctrl / ⌘ + E | Otvoriť úpravu podporovaného súboru. |
| F5 alebo Ctrl / ⌘ + Shift + R | Obnoviť zoznam súborov. |
| F1 | Otvoriť pomoc Prieskumníka vrátane jeho zoznamu skratiek. |

V **editore zdrojového kódu súboru** prepnete zobrazenie na celú obrazovku klávesom **F11** a opustíte ho klávesom **Esc**. Skratka **Alt + F** otvorí panel vyhľadávania, ktorý zostáva otvorený počas hľadania ďalších výskytov.
