Vy naprogramujete aplikáciu. Redaktor ju vloží do stránky.

Vlastný katalóg, kalkulačku či prehľad údajov môžete vytvoriť ako Spring MVC aplikáciu s Thymeleaf šablónou. Jej nastavenia sprístupníte v editore WebJET CMS.

Redaktor potom vyberie aplikáciu z katalógu, nastaví jej parametre a vloží ju tam, kde ju potrebuje. Vy zostávate zodpovední za jej funkcie, on za obsah stránky.

Administrácia nad vlastnými dátami

Na JPA entitu a Spring Data repozitár nadviažete REST controllerom a tabuľkovým editorom WebJET CMS. Využijete existujúce mechanizmy filtrovania, validácie a auditu pri tvorbe vlastných evidencií.

Prepojenia cez REST API

Prepojte CMS s ďalšími systémami cez REST služby. API kľúče sa viažu na používateľské kontá a ich oprávnenia; rozhrania si môžete prezrieť po zapnutí Swagger dokumentácie.

Vlastný frontend, spoločná redakcia

V headless režime poskytuje WebJET CMS obsah, navigáciu, novinky, vyhľadávanie a formuláre cez REST API. Frontend môžete postaviť napríklad na Astro, Reacte alebo Vue.

Redaktori naďalej pracujú vo WebJET CMS. Pre prvý projekt máte k dispozícii ukážkovú aplikáciu aj dokumentáciu k prenosu relácie a náhľadom obsahu.
