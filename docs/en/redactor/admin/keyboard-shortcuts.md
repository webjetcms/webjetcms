# Keyboard shortcuts

Open this overview from the administration header through **Help → Keyboard shortcuts**. Shortcuts depend on where you are working: the same keys can have different meanings in text, a data table or File Explorer.

**Ctrl / ⌘** means **Ctrl** on Windows and Linux and **Command (⌘)** on a Mac. **Alt** is **Option (⌥)** on a Mac. Function keys may also require holding **Fn**. If your browser or operating system handles a shortcut first, use the corresponding administration button.

## Search and administration controls

| Keys | Action | Where they work |
| --- | --- | --- |
| Ctrl / ⌘ + K | Open quick search. | Outside text fields, editors and open dialogs. |
| Alt + ← / → | Change the search scope. | In the quick search input. |
| ↑ / ↓ | Move to the previous or next result. | In the quick search input or on a result. |
| Enter | Run a search or open the focused result. | In the input or on a result link, respectively. |
| Esc | Close quick search and return focus to the header button. | In the quick search dialog. |
| Tab / Shift + Tab | Move to the next or previous control. | Throughout administration and dialogs. |
| Enter / Space | Activate a button; Enter also opens a link. | On the focused control. |

For details, see [Search](search/README.md).

## Data tables and saving

| Keys | Action | Where they work |
| --- | --- | --- |
| Ctrl / ⌘ + S | Save the record and keep the editor open. | In a data table editor, including the web page editor. Only one dialog may be open, and the application must support saving with this shortcut. |
| Enter / Space | Select or deselect a row. | On the focused table row itself, rather than a link inside it. |
| Enter / Space | Open cell editing. | On a cell when cell editing mode is enabled. |
| ↓ | Move from the date field into the calendar. | When the date picker is already open. |
| ← / → | Move by one day. | On a day in the calendar. |
| ↑ / ↓ | Move by one week. | On a day in the calendar. |
| Enter / Space | Select a day. | On a day in the calendar. |
| Esc | Close the date picker and return to the field. | In the open date picker. |

**Ctrl / ⌘ + S** also saves when you are editing web page text or working in Page Builder. Close any additional dialog, such as link settings, before using it. For more information, see [Data tables](../datatables/README.md).

## Web page text editor

Use these shortcuts while typing in the editor. In particular, **Ctrl / ⌘ + K** opens link settings here; it does not open administration quick search while you are typing.

| Keys | Action |
| --- | --- |
| Ctrl / ⌘ + B | Toggle bold. |
| Ctrl / ⌘ + I | Toggle italics. |
| Ctrl / ⌘ + U | Toggle underline. |
| Ctrl / ⌘ + K | Insert or edit a link. The editor also supports Ctrl / ⌘ + L when the browser does not intercept it. |
| Ctrl / ⌘ + Z | Undo the last text edit. |
| Ctrl / ⌘ + Y or Ctrl / ⌘ + Shift + Z | Redo a text edit. |
| Ctrl / ⌘ + A | Select the editor content. |
| Ctrl / ⌘ + C / X / V | Copy, cut or paste text. |
| Enter | Create a new paragraph. |
| Shift + Enter | Insert a line break within a paragraph. |
| Shift + Space | Insert a nonbreaking space. |
| Ctrl + Q | Switch to HTML source when available in the editor. On a Mac, use the **Source** button because ⌘ + Q quits the application. |
| Alt + F10 | Move focus to the editor toolbar. |
| Alt + F11 | Move focus to the HTML element path below the editor, when displayed. |
| Shift + F10 or Ctrl / ⌘ + Shift + F10 | Open the editor context menu. |
| Ctrl / ⌘ + Shift + 3 / 4 | Move to the previous or next paragraph insertion point offered by the helper line. |

Use **Paste as plain text** on the toolbar to insert unformatted text. Browsers also provide a shortcut for pasting without formatting; its keys depend on the browser and operating system. Use the corresponding toolbar button to paste from Word or Excel.

For details, see [Working in the editor](../webpages/working-in-editor/README.md).

## Welcome screen

These keys work while editing the overview or shortcuts on the [welcome screen](welcome.md).

| Keys | Action | Where they work |
| --- | --- | --- |
| Ctrl / ⌘ + Z | Undo the last overview change. | In overview editing mode, outside text fields and dialogs. |
| Space / Enter | Start moving a widget or shortcut. | On its move handle. |
| ← / → | Move the selected widget or shortcut. | After starting keyboard movement. |
| ↑ / ↓ | Move a widget to the previous or next row. | While moving a widget in the overview. |
| Enter / Space | Confirm the position. | During keyboard movement. |
| Esc | Cancel the move. | During keyboard movement. |
| Tab | Cancel the move and continue to the next control. | During keyboard movement. |

## Page Builder

Use these keys in the [Page Builder](../webpages/pagebuilder.md) structure tree:

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Move to the previous or next visible item. |
| ← | Collapse a branch or move to its parent. |
| → | Expand a branch or move to its first child. |
| Home / End | Move to the first or last visible item. |
| Enter / Space | Select an item for editing. |

On workbench and library tabs, use **← / →** to change tabs and **Home / End** to select the first or last tab.

## File Explorer and file editor

[File Explorer](../files/fbrowser/README.md) shortcuts work when its file area is active. Available operations depend on your permissions and the selected file or folder. When typing in a file editor, text editing shortcuts apply instead.

| Keys | Action |
| --- | --- |
| Arrow keys | Move the file selection. |
| Shift + arrow keys | Extend the file selection. |
| Home / End | Select the first or last file. |
| Ctrl / ⌘ + A | Select all files. |
| Ctrl / ⌘ + Shift + I | Invert the selection. |
| Ctrl / ⌘ + C / X / V | Copy, cut or paste files. |
| Ctrl / ⌘ + ↓ | Open the selected folder or file. Enter also works on Windows and Linux. |
| Ctrl / ⌘ + ↑ | Open the parent folder. |
| Ctrl / ⌘ + ← or Backspace | Go back. |
| Ctrl / ⌘ + → | Go forward. |
| Ctrl / ⌘ + Home or Ctrl / ⌘ + Shift + ↑ | Open the home folder. |
| Space | Open a quick preview. |
| F2 | Rename the selected file or folder. Enter also works on a Mac. |
| Shift + F2 | Rename multiple selected files in a batch. |
| Delete or Ctrl / ⌘ + Backspace | Start deleting the selected files. |
| Ctrl / ⌘ + Shift + N | Create a folder. |
| Ctrl / ⌘ + U | Open file upload. |
| Shift + Enter | Download the selected files. |
| Ctrl / ⌘ + I | Show information about the selection. |
| Ctrl / ⌘ + E | Open a supported file for editing. |
| F5 or Ctrl / ⌘ + Shift + R | Refresh the file list. |
| F1 | Open File Explorer help, including its shortcut list. |

In the **file source code editor**, press **F11** to toggle full screen and **Esc** to exit full screen. **Alt + F** opens a search bar that stays open while you find further matches.
