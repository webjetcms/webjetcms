# Keyboard shortcuts

You can open the overview from the administration header via **Help → Keyboard Shortcuts**. The shortcuts depend on where you are currently working: the same keys may have different meanings in text, a table, or Explorer.

The notation **Ctrl / ⌘** stands for **Ctrl** on Windows and Linux and **Command (⌘)** on Mac. **Alt** is the **Option (⌥)** key on Mac. For function keys, you may also need to hold **Fn**. If the shortcut is taken over by your browser or operating system, use the corresponding button in the administration.

## Search and control administration

| Keys | Activity | Where they work |
| --- | --- | --- |
| Ctrl / ⌘ + K | Open quick search. | Outside of text fields, editors, and open dialogs. |
| Alt + ← / → | Switch search scope. | In the quick search input field. |
| ↑ / ↓ | Go to the previous or next result. | In the input field or on the quick search result. |
| Enter | Start a search or open a highlighted result. | In the input field or on the result link. |
| Esc | Close quick search and return to the button in the header. | In the quick search dialog. |
| Tab / Shift + Tab | Go to the next or previous control. | In administration and dialogues. |
| Enter / space bar | Activate the button; Enter also opens the link. | On the element marked with a keyboard. |

Details are in the manual [Search](search/README.md).

## Data tables and storage

| Keys | Activity | Where they work |
| --- | --- | --- |
| Ctrl / ⌘ + S | Save the entry and leave the editor open. | In a spreadsheet editor, including a web page editor. Only one dialog box must be open, and the application must support saving by shortcut. |
| Enter / space bar | Select or deselect a row. | On the table row itself, selected by the keyboard, not on the link in the row. |
| Enter / space bar | Open cell editing. | On a cell with cell editing mode turned on. |
| Move from the date field to the calendar. | If the date selection is already open. | ← / → |
| Move forward one day. | On the days on the calendar. | ↑ / ↓ |
| Move forward a week. | On the days on the calendar. | Enter / space bar |
| Choose a day. | On the days on the calendar. | Esc |
| Close the date picker and return to the field. | In the open date selection. | V otvorenom výbere dátumu. |

Saving via **Ctrl / ⌘ + S** also works in the text of a web page and in the Page Builder. If you open another dialog, such as link settings, close it first. For more information about working with tables, see the [Datatables](../datatables/README.md) manual.

## Website text editor

The following shortcuts are used when typing in the editor. In particular, **Ctrl / ⌘ + K** opens the link settings here; the quick administration search does not open when typing.

| Keys | Activity |
| --- | --- |
| Ctrl / ⌘ + B | Turn bold text on or off. |
| Ctrl / ⌘ + I | Turn italics on or off. |
| Ctrl / ⌘ + U | Turn underlining on or off. |
| Ctrl / ⌘ + K | Insert or edit a link. The editor also supports Ctrl / ⌘ + L, unless the browser overrides it. |
| Ctrl/⌘ + Z | Undo the last text edit. |
| Ctrl/⌘ + Y or Ctrl/⌘ + Shift + Z | Redo the undone text edit. |
| Ctrl / ⌘ + A | Mark the editor content. |
| Ctrl / ⌘ + C / X / V | Copy, cut, or paste text. |
| Enter | Create a new paragraph. |
| Shift + Enter | Insert a line break in a paragraph. |
| Shift + Spacebar | Insert a fixed space at which the text does not wrap. |
| Ctrl + Q | Switch to HTML source code if the editor makes it available. On Mac, use the **Source** button because ⌘ + Q quits the application. |
| Alt + F10 | Move to the editor toolbar. |
| Alt + F11 | Move to the HTML element path below the editor, if displayed. |
| Shift + F10 or Ctrl / ⌘ + Shift + F10 | Open the editor context menu. |
| Ctrl / ⌘ + Shift + 3 / 4 | Move to the previous or next position to insert a paragraph using the guide line. |

Plain text insertion is available via the **Paste as Plain Text** button. The shortcut for pasting without formatting is also provided by the browser and its appearance depends on the browser and system. To paste from Word or Excel, use the appropriate button on the toolbar.

Details are in the [Working in the editor](../webpages/working-in-editor/README.md) manual.

## Home screen

These keys work while editing the overview or shortcuts on the [welcome screen](welcome.md).

| Keys | Activity | Where they work |
| --- | --- | --- |
| Ctrl/⌘ + Z | Undo the last edit to the report. | In report editing mode, outside of text fields and dialogs. |
| Spacebar / Enter | Start moving a widget or shortcut. | On the carrying handle. |
| ← / → | Move the selected widget or shortcut. | After starting to move with the keyboard. |
| ↑ / ↓ | Move the widget to the previous or next row. | When moving a widget in a report. |
| Enter / space bar | Confirm position. | When moving with the keyboard. |
| Esc | Cancel the move. | When moving with the keyboard. |
| Tab | Cancel moving and move to the next control. | When moving with the keyboard. |

## Page Builder

In the [Page Builder](../webpages/pagebuilder.md) tree structure, you can use these keys:

| Keys | Activity |
| --- | --- |
| ↑ / ↓ | Go to the previous or next visible element. |
| Collapse a branch or move to a parent element. | Expand a branch or go to its first nested element. |
| Home / End | Go to the first or last visible element. |
| Enter / space bar | Select the element to edit. |
| Enter / medzerník | Vybrať prvok na úpravu. |

On the taskbar and library tabs, use **← / →** to switch tabs and **Home / End** to the first or last tab.

## File explorer and editor

[Explorer](../files/fbrowser/README.md) shortcuts work when the file browser is active. The availability of operations is governed by your permissions and the selected file or folder. Text editor shortcuts are used when typing in the file editor.

| Keys | Activity |
| --- | --- |
| Darts | Move selection between files. |
| Shift + arrow keys | Expand file selection. |
| Home / End | Select the first or last file. |
| Ctrl / ⌘ + A | Select all files. |
| Ctrl / ⌘ + Shift + I | Invert selection. |
| Ctrl / ⌘ + C / X / V | Copy, cut, or paste files. |
| Ctrl / ⌘ + ↓ | Open the selected folder or file. Enter also works on Windows and Linux. |
| Ctrl / ⌘ + ↑ | Go to the parent folder. |
| Ctrl / ⌘ + ← or Backspace | Go back. |
| Ctrl / ⌘ + → | Go forward. |
| Ctrl / ⌘ + Home or Ctrl / ⌘ + Shift + ↑ | Go to your home folder. |
| Spacebar | Open quick preview. |
| F2 | Rename the selected file or folder. Enter also works on Mac. |
| Shift + F2 | Bulk rename multiple selected files. |
| Delete or Ctrl / ⌘ + Backspace | Start deleting selected files. |
| Ctrl / ⌘ + Shift + N | Create a folder. |
| Ctrl / ⌘ + U | Open file upload. |
| Shift + Enter | Download selected files. |
| Ctrl / ⌘ + I | Show selection information. |
| Ctrl / ⌘ + E | Open editing of a supported file. |
| F5 or Ctrl/⌘ + Shift + R | Refresh the file list. |
| F1 | Open Explorer help, including its list of shortcuts. |

In the **File Source Editor**, you can switch to full screen view with **F11** and exit with **Esc**. The shortcut **Alt + F** opens the search bar, which remains open while you search for more occurrences.
