# Klávesové zkratky

Přehled otevřete z hlavičky administrace přes **Pomocník → Klávesové zkratky**. Zkratky závisí na místě, kde právě pracujete: stejné klávesy mohou mít jiný význam v textu, tabulce nebo Průzkumníku.

Zápis **Ctrl / ⌘** znamená **Ctrl** ve Windows a Linuxu a **Command (⌘)** na Macu. **Alt** je na Macu klávesa **Option (⌥)**. U funkčních kláves může být nutné podržet také **Fn**. Pokud zkratku převezme prohlížeč nebo operační systém, použijte příslušné tlačítko v administraci.

## Vyhledávání a ovládání administrace

| Klávesy | Činnost | Kde fungují |
| --- | --- | --- |
| Ctrl / ⌘ + K | Otevřít rychlé vyhledávání. | Mimo textová pole, editor a otevřené dialogy. |
| Alt + ← / → | Přepnout rozsah vyhledávání. | Ve vstupním poli rychlého vyhledávání. |
| ↑ / ↓ | Přejít na předchozí nebo následující výsledek. | Ve vstupním poli nebo na výsledku rychlého vyhledávání. |
| Enter | Spustit vyhledávání nebo otevřít označený výsledek. | Ve vstupním poli, respektive na odkazu výsledku. |
| Esc | Zavřít rychlé vyhledávání a vrátit se na tlačítko v hlavičce. | V dialogu rychlého vyhledávání. |
| Tab / Shift + Tab | Přejít na následující nebo předchozí ovládací prvek. | V administraci a dialozích. |
| Enter / mezerník | Aktivovat tlačítko; Enter otevře také odkaz. | Na prvku označeném klávesnicí. |

Podrobnosti jsou v návodu [Vyhledávání](search/README.md).

## Datatabulky a ukládání

| Klávesy | Činnost | Kde fungují |
| --- | --- | --- |
| Ctrl / ⌘ + S | Uložit záznam a ponechat editor otevřený. | V editoru datatabulky včetně editoru webové stránky. Musí být otevřeno pouze jedno dialogové okno a aplikace musí podporovat ukládání zkratkou. |
| Enter / mezerník | Označit nebo odznačit řádek. | Na samotném řádku tabulky označeném klávesnicí, nikoli na odkazu v řádku. |
| Enter / mezerník | Otevřít úpravu buňky. | Na buňce v zapnutém režimu úpravy buněk. |
| ↓ | Přesunout se z pole data do kalendáře. | Pokud je výběr data již otevřený. |
| ← / → | Posunout se o jeden den. | Na dni v kalendáři. |
| ↑ / ↓ | Posunout se o týden. | Na dni v kalendáři. |
| Enter / mezerník | Vybrat den. | Na dni v kalendáři. |
| Esc | Zavřít výběr data a vrátit se do pole. | V otevřeném výběru data. |

Uložení přes **Ctrl / ⌘ + S** funguje také v textu webové stránky a v Page Builderu. Pokud otevřete další dialog, například nastavení odkazu, nejprve jej zavřete. Více o práci s tabulkami je v návodu [Datatabulky](../datatables/README.md).

## Textový editor webových stránek

Následující zkratky se používají při psaní v editoru. Zejména **Ctrl / ⌘ + K** zde otevře nastavení odkazu; rychlé vyhledávání administrace se při psaní neotevírá.

| Klávesy | Činnost |
| --- | --- |
| Ctrl / ⌘ + B | Zapnout nebo vypnout tučné písmo. |
| Ctrl / ⌘ + I | Zapnout nebo vypnout kurzívu. |
| Ctrl / ⌘ + U | Zapnout nebo vypnout podtržení. |
| Ctrl / ⌘ + K | Vložit nebo upravit odkaz. Editor podporuje také Ctrl / ⌘ + L, pokud jej nepřevezme prohlížeč. |
| Ctrl / ⌘ + Z | Vrátit poslední úpravu textu. |
| Ctrl / ⌘ + Y nebo Ctrl / ⌘ + Shift + Z | Zopakovat vrácenou úpravu textu. |
| Ctrl / ⌘ + A | Označit obsah editoru. |
| Ctrl / ⌘ + C / X / V | Kopírovat, vyjmout nebo vložit text. |
| Enter | Vytvořit nový odstavec. |
| Shift + Enter | Vložit zalomení řádku v odstavci. |
| Shift + mezerník | Vložit pevnou mezeru, na které se text nezalomí. |
| Ctrl + Q | Přepnout na zdrojový HTML kód, pokud jej editor zpřístupňuje. Na Macu použijte tlačítko **Zdroj**, protože ⌘ + Q ukončuje aplikaci. |
| Alt + F10 | Přesunout se na panel nástrojů editoru. |
| Alt + F11 | Přesunout se na cestu HTML elementů pod editorem, pokud je zobrazena. |
| Shift + F10 nebo Ctrl / ⌘ + Shift + F10 | Otevřít kontextové menu editoru. |
| Ctrl / ⌘ + Shift + 3 / 4 | Přesunout se na předchozí nebo následující místo pro vložení odstavce pomocí pomocné čáry. |

Vložení čistého textu je dostupné přes tlačítko **Vložit jako čistý text**. Zkratku pro vložení bez formátování poskytuje také prohlížeč a její podoba závisí na prohlížeči a systému. Pro vložení z Wordu nebo Excelu použijte příslušné tlačítko na panelu nástrojů.

Podrobnosti jsou v návodu [Práce v editoru](../webpages/working-in-editor/README.md).

## Úvodní obrazovka

Tyto klávesy fungují během úpravy přehledu nebo zkratek na [úvodní obrazovce](welcome.md).

| Klávesy | Činnost | Kde fungují |
| --- | --- | --- |
| Ctrl / ⌘ + Z | Vrátit poslední úpravu přehledu. | V režimu úpravy přehledu, mimo textová pole a dialogy. |
| Mezerník / Enter | Zahájit přesouvání widgetu nebo zkratky. | Na úchytu pro přesouvání. |
| ← / → | Přesunout vybraný widget nebo zkratku. | Po zahájení přesouvání klávesnicí. |
| ↑ / ↓ | Přesunout widget do předchozího nebo následujícího řádku. | Při přesouvání widgetu v přehledu. |
| Enter / mezerník | Potvrdit pozici. | Při přesouvání klávesnicí. |
| Esc | Zrušit přesouvání. | Při přesouvání klávesnicí. |
| Tab | Zrušit přesouvání a přejít na další ovládací prvek. | Při přesouvání klávesnicí. |

## Page Builder

Ve stromové struktuře [Page Builderu](../webpages/pagebuilder.md) můžete používat tyto klávesy:

| Klávesy | Činnost |
| --- | --- |
| ↑ / ↓ | Přejít na předchozí nebo následující viditelný prvek. |
| ← | Sbalit větev nebo přejít na nadřazený prvek. |
| → | Rozbalit větev nebo přejít na její první vnořený prvek. |
| Home / End | Přejít na první nebo poslední viditelný prvek. |
| Enter / mezerník | Vybrat prvek k úpravě. |

Na kartách pracovního panelu a knihovny použijte **← / →** k přepnutí karty a **Home / End** pro první nebo poslední kartu.

## Průzkumník a editor souborů

Zkratky [Průzkumníka](../files/fbrowser/README.md) fungují, když je aktivní jeho plocha se soubory. Dostupnost operací se řídí vašimi oprávněními a vybraným souborem nebo složkou. Při psaní v editoru souboru se používají zkratky textového editoru.

| Klávesy | Činnost |
| --- | --- |
| Šipky | Přesouvat výběr mezi soubory. |
| Shift + šipky | Rozšířit výběr souborů. |
| Home / End | Vybrat první nebo poslední soubor. |
| Ctrl / ⌘ + A | Vybrat všechny soubory. |
| Ctrl / ⌘ + Shift + I | Obrátit výběr. |
| Ctrl / ⌘ + C / X / V | Kopírovat, vyjmout nebo vložit soubory. |
| Ctrl / ⌘ + ↓ | Otevřít vybranou složku nebo soubor. Ve Windows a Linuxu funguje také Enter. |
| Ctrl / ⌘ + ↑ | Přejít do nadřazené složky. |
| Ctrl / ⌘ + ← nebo Backspace | Přejít zpět. |
| Ctrl / ⌘ + → | Přejít vpřed. |
| Ctrl / ⌘ + Home nebo Ctrl / ⌘ + Shift + ↑ | Přejít do domovské složky. |
| Mezerník | Otevřít rychlý náhled. |
| F2 | Přejmenovat vybraný soubor nebo složku. Na Macu funguje také Enter. |
| Shift + F2 | Hromadně přejmenovat více vybraných souborů. |
| Delete nebo Ctrl / ⌘ + Backspace | Spustit odstranění vybraných souborů. |
| Ctrl / ⌘ + Shift + N | Vytvořit složku. |
| Ctrl / ⌘ + U | Otevřít nahrávání souborů. |
| Shift + Enter | Stáhnout vybrané soubory. |
| Ctrl / ⌘ + I | Zobrazit informace o výběru. |
| Ctrl / ⌘ + E | Otevřít úpravu podporovaného souboru. |
| F5 nebo Ctrl / ⌘ + Shift + R | Obnovit seznam souborů. |
| F1 | Otevřít pomoc Průzkumníka včetně jeho seznamu zkratek. |

V **editoru zdrojového kódu souboru** přepnete zobrazení na celou obrazovku klávesou **F11** a opustíte jej klávesou **Esc**. Zkratka **Alt + F** otevře panel vyhledávání, který zůstává otevřený během hledání dalších výskytů.
